An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every official name, description and grade, a guide in our own words with cited sources for each trophy, a roadmap to the platinum, missable flags, per-trophy progress counters, filters by kind, a spoiler setting that hides story trophies until earned, and export/import of progress — all as static files under `app/` that run with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or hand it in with `MAKEFUN_OUTPUT_DIR=out node main.ts`, which copies `app/` and `screenshots/` to `out/` and writes `out/dossier.json`.
